# स्वयं-संकलकः (Sutra Self-Hosting Compiler Status)

This document describes the design, status, and roadmap for building a self-hosted compiler for the Sutra programming language.

---

## 1. Current Status

* **Milestone M4-11 (स्वसंकलक आधार-सुदृढीकरण / Self-Hosting Compiler Foundation)**: **COMPLETE**
  - **Zero-English Rule Compliance**: The self-hosted compiler source code (`स्वसंकलक/विश्लेषक.सूत्र`, `स्वसंकलक/विश्लेषक_परीक्षण.सूत्र`, etc.) is fully compliant with the mandatory rule: zero English alphabet characters (including strings, comments, and escape character representations like `\न` instead of `\n`).
  - **AST Equivalence Verified**: The C++ Stage 0 compiler successfully compiles the self-hosted parser. Both the interpreted Stage 0 run and the natively compiled Stage 1 executable produce 100% binary-identical AST output dumps on the target test files.
  - **GC & Type Conversion Optimizations**: Resolved interpreter memory issues during complex parsing phases. Fixed dynamic pointer-to-string conversion bugs when printing dictionary-retrieved node values in natively compiled binaries.

## 3. Bootstrap Roadmap

Once active, the self-hosting compiler development will progress through the following bootstrapping stages:

```text
       C++ Sutra Compiler (sutra.exe)
                     ↓ compiles
     Sutra Self-Hosted Compiler (स्वसंकलक)
                     ↓ compiles
   Self-Hosted Output Executable (स्वयं-उत्पाद)
```

1. **Stage 1 (C++ Host)**: The C++ compiler (`sutra.exe`) compiles the self-hosted compiler source code (written in Sutra) into a native machine binary (`sutra_self.exe`).
2. **Stage 2 (Self-Host compile)**: The generated `sutra_self.exe` compiler is run, taking its own Sutra source files as input, to compile itself.
3. **Stage 3 (Verification)**: The binary generated by the self-hosted compiler is byte-compared against `sutra_self.exe` to ensure functional parity and identity convergence.
