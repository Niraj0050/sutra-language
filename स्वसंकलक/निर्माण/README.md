# स्वसंकलक/निर्माण/ — बूटस्ट्रैप बीज (Bootstrap Seed)

यह निर्देशिका सूत्र संकलक को **C++ host और C runtime दोनों के बिना** खड़ा
करने की सामग्री रखती है। **कोई C सञ्चिका नहीं** (`sutra_runtime.c` §2r में
हटा दी गई — पूरा runtime अब `तल.s` + `मूल_रनटाइम.सूत्र` + `मूल_आवंटक.सूत्र`)।

## सामग्री

| सञ्चिका | क्या है |
|---|---|
| `मूल_संकलन.s` | जमी हुई x86-64 असेम्बली — सूत्र native संकलक (`स्वसंकलक/मूल_संकलन.सूत्र` + आयातित) का पूर्ण output, स्वयं सूत्र संकलक द्वारा उत्पन्न। यही "बीज" है। |
| `तल.s` | हाथ से लिखा OS-तल — kernel32 wrappers (VirtualAlloc / WriteFile / CreateProcessW / stderr / ExitProcess), mem/str primitives, setjmp/longjmp, float SSE, GC रूट-स्टैक। शून्य C, शून्य libc। |
| `मूल_रनटाइम.सूत्र` (+ `.s`) | runtime के पत्ते सूत्र में — string/list/dict ops, print, exceptions, file I/O composition, दशमलव प्रारूपण, pow/ln/exp, gc_status। |
| `मूल_आवंटक.सूत्र` (+ `.s`) | VirtualAlloc arena + mark-sweep GC, सूत्र में। |

## प्रयोग

रेपो-मूल से:

```powershell
powershell -ExecutionPolicy Bypass -File bootstrap.ps1
```

यह:
1. `.s` सञ्चिकाएँ (`मूल_संकलन.s` + `तल.s` + `मूल_रनटाइम.s` + `मूल_आवंटक.s`) को `as` से `.o` में असेम्बल करता है
2. `gcc` (केवल linker रूप में) से जोड़कर `seed_sutrac.exe` बनाता है
3. उस seed संकलक से current `.सूत्र` स्रोत को संकलित करके `sutrac.exe` बनाता है
4. fixed-point जाँच — seed और ताज़ा संकलक समान असेम्बली दें

**आवश्यक:** MSYS2 ucrt64 (`C:\msys64\ucrt64\bin`) — `as`, `gcc` (linker), `ld`।
C++ संकलक, `sutra.exe` (C++ host), C compiler, या `संकलक/` की कोई आवश्यकता नहीं।

## बीज कब ताज़ा करें

`विश्लेषक.सूत्र` / `सार्थक_विश्लेषक.सूत्र` / `मूल_निम्नक.सूत्र` / `अनुकूलक.सूत्र` /
`रजि_नियतक.सूत्र` / `मूल_उत्सर्जक.सूत्र` / `मूल_संकलन.सूत्र` में codegen-प्रभावी
बदलाव के बाद। पुराना बीज भी काम करता है — वह बस पुराने बिंदु से शुरू करता है,
और चरण 3 में ताज़ा संकलक फिर भी current स्रोत से बनता है।

ताज़ा करने के लिए (एक कार्यशील संकलक चाहिए — seed या पूर्व-निर्मित):

```powershell
.\sutrac.exe स्वसंकलक\मूल_संकलन.सूत्र
copy /y sutra_native_temp.s स्वसंकलक\निर्माण\मूल_संकलन.s
```

`मूल_रनटाइम.सूत्र` / `मूल_आवंटक.सूत्र` / `तल.s` बदलने पर उनके `.s` भी पुनर्जनित करें
(`.\sutrac.exe स्वसंकलक\निर्माण\मूल_रनटाइम.सूत्र` → `copy sutra_native_temp.s …`)।
