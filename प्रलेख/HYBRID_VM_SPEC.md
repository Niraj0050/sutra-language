# सूत्र आभासी यंत्र (SVM) एवं संकर निष्पादन विनिर्देश
## Phase 4: Sutra Virtual Machine (SVM) & Hybrid Execution Architecture

---

## 🌺 १. द्वि-अंक दर्शन (Sanskrit Binary Philosophy — ० एवं १)

भारतीय गणित और छन्दःशास्त्र (आचार्य पिंगलकृत *छन्दःसूत्रम्*, ई.पू. ३००) बाइनरी गणित का प्राचीनतम ऐतिहासिक मूल है, जहाँ लघु (`१` / `एकम्`) और गुरु (`०` / `शून्यम्`) के संयोग से द्वि-अंक प्रणाली की नींव रखी गई थी।

सूत्र आभासी यंत्र (SVM) में 0 और 1 को संस्कृत-निष्ठ रूप में स्थापित किया गया है:

| संकल्पना (Concept) | संस्कृत संज्ञा (Sanskrit Term) | देवनागरी संकेत | अर्थ / स्वरूप |
|---|---|:---:|---|
| **Bit (Binary Digit)** | **द्वि-अंक** / **बिन्दु** | `०` / `१` | लघुतम सूचना इकाई |
| **Bit 0** | **शून्यम्** (Śūnyam) | `०` | अभाव, असत्य (`असत्य`), आधार स्थिति |
| **Bit 1** | **एकम्** (Ekam) | `१` | भाव, सत्य (`सत्य`), सक्रिय स्थिति |
| **Byte (8 Bits)** | **अष्टक** (Ashtaka) | `[८ द्वि-अंक]` | ८ द्वि-अंकों का समूह (उदा. `०००००००१`) |
| **Bytecode** | **अष्टक-संकेत** (Ashtaka-Saṅketa) | — | पोर्टेबल मध्यवर्ती आज्ञा-कूट |
| **Virtual Machine** | **सूत्र आभासी यंत्रम् (SVM)** | — | अष्टक-संकेत निष्पादक कल्पित-यंत्र |
| **Opcode** | **क्रिया-संकेत** / **आज्ञा** | — | संक्रिया का संख्यात्मक अष्टक |
| **Register / Slot** | **धारक** / **कोष्ठक** | `क०..क१५` | संक्रिया मान रखने वाला स्थान |

## ⚡ २. संकर निष्पादन प्रारूप (Hybrid Execution Architecture)

**नियम:**
1. यदि निष्पादन उसी यंत्र/आर्किटेक्चर पर हो रहा है जिसके लिए संकलन किया गया था, तो कोड **सीधे मशीन (CPU) पर प्रत्यक्ष निष्पादित (Direct Native Execution)** होगा।
2. यदि कोड किसी भिन्न यंत्र या आर्किटेक्चर (उदा. भिन्न CPU, भिन्न OS) पर निष्पादित किया जा रहा है, तो वही कोड **सूत्र आभासी यंत्र (SVM)** के माध्यम से बिना किसी पुनर्compilation के संचालित होगा।

### २.१ संकर संचिका प्रारूप (`.सूत्रक` / Sutra Hybrid Container)

```text
+-------------------------------------------------------------+
|        सूत्र संकर संचिका शीर्षलेख (Hybrid Container Header)        |
|  - जादुई संकेत (Magic):   'स','ू','त','्','र' (UTF-8)        |
|  - संस्करण (Version):     १.० (एकम्.शून्यम्)                |
|  - लक्ष्य-यंत्र (Target): x86_64_windows / सार्वत्रिक       |
|  - द्वि-अंक ध्वज (Flags): प्रत्यक्ष-उपलब्ध = १, आभासी = १     |
+-------------------------------------------------------------+
|  खण्ड १: प्रत्यक्ष मशीन कोड (Native Machine Code - x86-64)   |
|         (केवल तभी निष्पादित जब वर्तमान यंत्र == लक्ष्य-यंत्र)   |
+-------------------------------------------------------------+
|  खण्ड २: सार्वत्रिक अष्टक-संकेत (Universal SVM Bytecode)      |
|         (भिन्न यंत्र / OS होने पर SVM द्वारा निष्पादित)      |
+-------------------------------------------------------------+
```

### २.२ निष्पादन प्रवाह (Execution Flow)

```text
[प्रोग्राम प्रारंभ]
       ↓
[शीर्षलेख पठन]
       ↓
[यंत्र-पहचान जाँच: वर्तमान यंत्र == लक्ष्य-यंत्र?]
      /            \
   हाँ (१)        नहीं (०) / सार्वत्रिक
    /                \
[प्रत्यक्ष मशीन निष्पादन]     [सूत्र आभासी यंत्र (SVM) निष्पादन]
(Zero-overhead CPU speed)      (100% Cross-platform portability)
```

## 📜 ३. अष्टक-संकेत आज्ञा-सूची (SVM Bytecode Instruction Set)

हर निर्देश का **क्रिया-संकेत** (Opcode) एक **अष्टक** (Byte) होता है, जिसके द्वि-अंक `०` और `१` में व्यक्त होते हैं:

| क्रिया-संकेत (हेक्स) | अष्टक (८ द्वि-अंक: ०/१) | आज्ञा नाम | विवरण (Operation) |
|:---:|:---:|---|---|
| `०x००` | `००००००००` | **`विराम`** | निष्पादन समाप्त करो (Halt/Exit) |
| `०x०१` | `०००००००१` | **`स्थिर`** | स्थिरांक मान को धारक में रखो (Load Constant) |
| `०x०२` | `००००००१०` | **`योग`** | `क[ग] = क[अ] + क[ब]` (Add) |
| `०x०३` | `००००००११` | **`अंतर`** | `क[ग] = क[अ] - क[ब]` (Subtract) |
| `०x०४` | `०००००१००` | **`गुणा`** | `क[ग] = क[अ] * क[ब]` (Multiply) |
| `०x०५` | `०००००१०१` | **`भाग`** | `क[ग] = क[अ] / क[ब]` (Divide) |
| `०x०६` | `०००००११०` | **`शेष`** | `क[ग] = क[अ] % क[ब]` (Modulo) |
| `०x०७` | `०००००१११` | **`सम`** | `क[ग] = (क[अ] == क[ब])` → `१` अथवा `०` |
| `०x०८` | `००००१०००` | **`असम`** | `क[ग] = (क[अ] != क[ब])` → `१` अथवा `०` |
| `०x०९` | `००००१००१` | **`लघु`** | `क[ग] = (क[अ] < क[ब])` → `१` अथवा `०` |
| `०x०A` | `००००१०१०` | **`गुरु`** | `क[ग] = (क[अ] > क[ब])` → `१` अथवा `०` |
| `०x०B` | `००००१०११` | **`लघुसम`** | `क[ग] = (क[अ] <= क[ब])` → `१` अथवा `०` |
| `०x०C` | `००००११००` | **`गुरुसम`** | `क[ग] = (क[अ] >= क[ब])` → `१` अथवा `०` |
| `०x१०` | `०००१००००` | **`जाओ`** | बिना शर्त निर्दिष्ट पते पर जाओ (Jump) |
| `०x११` | `०००१०००१` | **`यदि_जाओ`** | यदि शर्त == `१` (`एकम्`) तो जाओ (Jump If True) |
| `०x१२` | `०००१००१०` | **`बुलाओ`** | फलन आह्वान (Call Function) |
| `०x१३` | `०००१००११` | **`वापस`** | फलन से मान लौटाओ (Return) |
| `०x१४` | `०००१००२०` | **`छापो`** | धारक का मान कंसोल पर मुद्रित करो (`लिखतु`) |
| `०x१५` | `०००१००२१` | **`नव_सूची`** | नवीन सूची आवंटित करो (New List) |
| `०x१६` | `०००१०११०` | **`नव_शब्दकोश`**| नवीन शब्दकोश आवंटित करो (New Dictionary) |
| `०x१७` | `०००१०१११` | **`पढ़_अनुक्रम`**| `क[ग] = क[आधार][क[सूचक]]` (Index Read) |
| `०x१८` | `०००१८०००` | **`लिख_अनुक्रम`**| `क[आधार][क[सूचक]] = क[मान]` (Index Write) |
| `०x१९` | `०००१८००१` | **`लंबाई`** | `क[ग] = लंबाई(क[आधार])` (Length) |

## 🔍 ४. अष्टक-संकेत विच्छेदन दृश्य (Disassembler View)

विच्छेदक दृश्य में अष्टक बाइनरी `०` और `१` के रूप में प्रदर्शित होते हैं:

```text
[पङ्क्ति ००००]  अष्टक: ०००००००१ (स्थिर)       धारक: क१    मान: १०
[पङ्क्ति ०००४]  अष्टक: ०००००००१ (स्थिर)       धारक: क२    मान: २०
[पङ्क्ति ०००८]  अष्टक: ००००००१० (योग)         धारक: क१, क२ → क३
[पङ्क्ति ०००C]  अष्टक: ०००१००१४ (छापो)        धारक: क३
[पङ्क्ति ००१०]  अष्टक: ०००१००१३ (वापस)
```
