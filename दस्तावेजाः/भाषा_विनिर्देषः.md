# सूत्र (Sutra) — संस्कृत प्रोग्रामिंग भाषा विनिर्देषः (Language Specification)

---

## 1. भाषायाः उद्देश्यम् (Language Goals)

**सूत्र (Sutra)** एका स्वतंत्रा, आधुनिका, general-purpose प्रोग्रामिंग भाषा अस्ति। अस्याः मुख्यमुरुद्देश्यं संस्कृतभाषायां संगणक-प्रोग्रामणं (computer programming) सुलभं विधातुम् अस्ति।

इयं भाषा न केवलं कस्याश्चिद् अन्यस्याः भाषायाः (यथा C++, JavaScript) अनुवादः, अपि तु अस्याः स्वकीयम्:
* व्याकरणम् (Syntax)
* अर्थविज्ञानम् (Semantics)
* संकलकः (Compiler)
* अनुष्ठान-प्रणाली (Runtime)
* मानक-पुस्तकालयः (Standard Library)
* उपकरणानि (Tooling & CLI)

## 3. संकलक-संरचना (Compiler Architecture)

```text
सूत्र स्रोत कोड (*.सूत्र)
        ↓
अक्षर-वाचकः (Lexer) — UTF-8 Tokenizer
        ↓
वाक्य-विच्छेदकः (Parser) — Abstract Syntax Tree (AST) Builder
        ↓
अर्थ-परीक्षणम् (Semantic Analysis) — Scope & Type Checking
        ↓
व्याख्याता (Interpreter & Runtime) — Execution Engine
        ↓
उत्पादम् (Output)
```

## 4. उदाहरणानि (Examples)

### 4.1 नमस्ते जगत् (Hello World)

```text
कार्य मुख्य() {
    लिखतु("नमस्ते जगत्!");
}
```

### 4.2 अङ्कगणितम् (Arithmetic)

```text
कार्य मुख्य() {
    संख्या अ = 10;
    संख्या ब = 20;
    संख्या परिणामः = अ + ब;
    लिखतु("परिणामः अस्ति:");
    लिखतु(परिणामः);
}
```

### 4.3 अवस्था-परीक्षणम् (Conditionals)

```text
कार्य मुख्य() {
    संख्या वयः = 22;
    यदि (वयः >= 18) {
        लिखतु("वयस्कः");
    } अन्यथा {
        लिखतु("अवयस्कः");
    }
}
```

### 4.4 कार्यम् (Functions)

```text
कार्य जोड़ना(संख्या अ, संख्या ब) {
    परत् अ + ब;
}

कार्य मुख्य() {
    संख्या उत्तरम् = जोड़ना(15, 25);
    लिखतु(उत्तरम्);
}
```

## 5. उपकरणानि (CLI Command Workflow)

सूत्र भाषायाम् प्रोग्राम निष्पादनार्थम् कमान:

```cmd
सूत्र चलाओ नमस्ते.सूत्र
```

वा PowerShell मध्ये:

```powershell
.\उपकरणानि\सूत्र.ps1 चलाओ नमस्ते.सूत्र
```

## 6. भविष्यत्-मार्गचित्रम् (Future Roadmap)

1. **चरण 1**: Basic Language & Interpreter (संपन्नम्)
2. **चरण 2**: Arrays & Objects (`सूची`, `वर्ग`)
3. **चरण 3**: Standard Library (`मानक-पुस्तकालयः`)
4. **चरण 4**: Bytecode & Sutra Virtual Machine (SVM)
5. **चरण 5**: Native Machine Code via LLVM
6. **चरण 6**: Self-hosting Sutra Compiler (`स्वयं-संकलकः`)
